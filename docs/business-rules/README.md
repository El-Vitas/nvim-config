# Behavior rules of the config

This registry says **what the editor has to do**: what each tree shows, when the session is saved, what counts as a hidden file. If a rule stops being met, there is a bug, even if the code "works".

The **technical why** of each implementation (which git flag is used, why one timer and not another) does not go here. It goes in [`../decisions.md`](../decisions.md). A rule has to be explainable without naming a plugin or a file; a decision does not.

## Files

- `fea-*.yaml`: one file per area of the editor (tree, session, search…). It is the source of truth and is versioned.
- `fea-template.yaml`: template for a new area. The CLI does not index it.
- `rules.db` and `history/`: generated by the CLI and not versioned.

## How to use it

The YAML files are not read or edited by hand: they are queried and added to with the CLI, which needs [bun](https://bun.sh). The first time, run `bun install` at the root of this repo.

```bash
bun run rules:build                    # rebuilds rules.db from the YAML
bun run rules:query --features --names # which areas exist
bun run rules:query --feature FEA-TRE  # active rules of an area
bun run rules:query --id BR-xxxxxxx    # one rule with its history
bun run rules:add < rule.yaml          # adds a rule (the id is generated by the CLI)
bun run rules:delete --id BR-xxxxxxx   # only for a material mistake
```

The `.agents/skills/business-rules` skill explains the format of `rules:add` and the full lifecycle.

## Conventions

- Area: `FEA-` plus three letters (`FEA-TRE`, `FEA-SES`).
- Rule: `BR-` plus the first 7 characters of a sha256 of the area and the rule text. The CLI computes it, so the same rule always has the same id.
- Status: `active`, `superseded` or `inactive`.
- Every rule carries `why`. A rule without a reason is not added.
- A rule that changed is replaced with `supersedes`, and the old one stays linked to the new one. `delete` is only for what should never have existed: the wrong area, the same rule submitted twice, a half-written submission.
